# Images folder

Add the following image files to this folder (copy from `foodies/src/assets/`):

| Filename          | Used by                     | Source file           |
|-------------------|-----------------------------|-----------------------|
| `header1.jpg`     | Header carousel – slide 1   | (add your own)        |
| `header2.jpg`     | Header carousel – slide 2   | (add your own)        |
| `header3.jpg`     | Header carousel – slide 3   | (add your own)        |
| `bg1.png`         | Login / Register background | `foodies/src/assets/bg1.png` |
| `bg2.png`         | Alternative background      | `foodies/src/assets/bg2.png` |
| `meat.png`        | Category: Eggs, Meat & Fish | `foodies/src/assets/meat.png` |
| `fruit.png`       | Category: Fruits & Vegetables | `foodies/src/assets/fruit.png` |
| `dairy.png`       | Category: Bakery, Cakes & Dairy | `foodies/src/assets/dairy.png` |
| `drink.png`       | Category: Beverages         | `foodies/src/assets/drink.png` |

All images are served from `/images/<filename>` by the Vite dev server.
